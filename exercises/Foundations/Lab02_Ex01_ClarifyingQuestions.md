# Exercice (Lab02) — ClarifyingQuestions : forcer 0 à 2 questions

## Objectif
Dans `Lab02_StructuredDraft`, ajuster l’instruction pour que `ClarifyingQuestions` contienne :
- 0 question si la demande est claire
- 2 questions max si la demande est ambiguë

## Tests
- Clair : « Le bouton Enregistrer ne fonctionne plus depuis la v2.3 »
- Ambigu : « Ça marche pas depuis hier »

## Critère de réussite
- clair → 0 question
- ambigu → 1 à 2 questions
