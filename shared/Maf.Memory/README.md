# Maf.Memory

Infrastructure pédagogique du Lot-006 : stockage SQLite explicite, enveloppe de session MAF, mémoire bornée avec provenance et admission stricte des déclarations key=value, extraction sans session, AIContextProvider et compaction MAF native.

Voir le [guide complet](../../docs/lot-006/SessionsAndMemory.md). Les instructions métier sont ici et dans les exemples ; Maf.DemoConnection reste limité à la connexion. Le contrat d'admission est volontairement étroit : une citation exacte seule ne prouve pas qu'un modèle a choisi la bonne clé sémantique.
